## 壁击（Wall Run）物理惯性累加与超长滑翔机制
在《永劫无间》三维立体地图中，墙面、树木与岩壁是顶尖身法选手的超级跳板：
- 贴墙判定与壁击蓄力：当角色靠近墙体或柱子时，身体自动吸附并进入攀爬挂墙状态。此时长按左键或右键即可进行‘壁击蓄力’；
- 惯性冲量放大：壁击出手瞬间，角色以近乎三倍持刀奔跑的极限速度向前弹射冲刺，且飞行期间处于蓝霸体护体状态；
- 连续踩墙反弹：在不生锈的城楼回廊或天人城高阁之间，通过连续利用两侧墙面进行壁击衔接，角色可以在半空中连续滑行数百米不落地，任何地面追击者都会被瞬间甩开视野。

## 滑铲跳（Slide Jump）耐力循环与无声跑图规范
平地移动速度最大化且节省精力的标准手法：
- 动作节拍：奔跑状态下按 C 键触发滑铲 ➔ 在滑铲滑行至第 0.3 秒速度达到峰值的瞬间按空格起跳 ➔ 空中保持向前惯性 ➔ 落地瞬间再次接 C 滑铲；
- 耐力零惩罚：通过滑跳，角色的前移速度比纯粹按 Shift 奔跑快约 25%，且每次起跳在空中具有 0.5 秒的耐力自然恢复窗口，实现全图跑毒精力条时刻保持全满状态；
- 消除脚步声技巧：频繁滑铲能大幅降低奔跑时的踏步声波，在耳机听声辨位雷达上极难被敌人捕捉锁定。
