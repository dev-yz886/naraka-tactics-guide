## 图形 API 选择：DX11 与 DX12 优劣深度对比
《永劫无间》基于 Unity 引擎深度定制，图形接口的选择直接决定了战斗激烈时的最低瞬时帧率（1% Low）：
- DX11 模式（成熟稳定之选）：驱动兼容性最好，着色器加载极为平稳，极少出现突然卡死。对于老款显卡（GTX 10/16系列、RTX 20系列），DX11 是保证帧率绝对平稳的最佳选项；
- DX12 模式（现代架构加速）：在 RTX 30/40 系列显卡以及最新 Windows 11 环境下，DX12 能够充分调动多核多线程 CPU 吞吐能力，大幅改善天人城数十人混战时的 CPU 瓶颈，并原生支持 Reflex 超低延迟技术；
- 结论：高端多核配置果断选择 DX12，中低端主流平台推荐坚持 DX11。

## 职业选手电竞画质参数最优调校模板
要在对局中快人一步看清敌方出招红蓝光芒，必须精简画面多余特效：
- 分辨率与长宽比：原生 1080P 或 2K 匹配显示器物理分辨率；
- 建模精度（高）：保证远距离敌人轮廓清晰可见；
- 特效品质（中或低）：太高的特效会导致奥义对撞时屏幕全是光污染，完全遮蔽了对手的蓄力与振刀动作；
- 阴影与体积光（极低）：关闭不必要的动态阴影计算，不仅释放 20% GPU 算力，还能让躲在树荫与屋内的敌人无所遁形；
- 垂直同步与运动模糊（强制关闭）：彻底斩断显示延迟与晃动拖影。
